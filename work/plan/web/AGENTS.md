# Web 規劃規範

## 1. 適用範圍

1. 本規則適用於 Web 系統的跨層規劃。
2. 規劃應同時考量使用者介面、API、資料流、驗證、安全性、可觀測性及部署影響。
3. 更具體的技術領域規則由後續階層補充，例如 `web/backend` 與 `web/backend/java`。

## 2. 規劃原則

1. 先界定使用者流程、系統邊界與前後端責任，再拆分實作步驟。
2. 明確描述介面契約、錯誤處理、相容性及資料一致性要求。
3. 將安全性、效能、可存取性、測試與發布驗證納入規劃。
4. 跨層變更必須列出受影響元件、依賴關係及整合順序。

## 3. 規劃輸出

1. 說明目標、範圍、限制與驗收條件。
2. 依依賴順序列出最小可驗證步驟。
3. 標示風險、待確認事項及回復策略。
