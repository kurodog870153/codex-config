# Web 任務規範

## 1. 適用範圍

1. 本規則適用於 Web 系統的跨層任務拆分與執行。
2. 任務應涵蓋實際受影響的介面、API、資料流、驗證、安全性、測試及部署項目。
3. 更具體的技術領域規則由後續階層補充，例如 `web/backend` 與 `web/backend/java`。

## 2. 任務原則

1. 每個任務只產生一個明確且可驗證的成果。
2. 跨前後端變更應先確認介面契約，再依依賴順序安排工作。
3. 任務必須列出修改範圍、驗證方式、相容性影響及已知風險。
4. 不得將未確認的跨層需求或部署操作納入執行範圍。

## 3. 完成條件

1. 實作符合既有架構與介面契約。
2. 已執行與變更範圍相符的測試及靜態檢查。
3. 已記錄未驗證項目、剩餘風險與必要的後續工作。
